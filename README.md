# MEDTECH -- Hospital Consultation Application

![MEDTECH GitHub Banner](MEDTECH-GitHub-Banner.png)

A UI/UX design project for a hospital consultation application, created
in **Figma**. MEDTECH explores how patients and healthcare professionals
could access consultation-related services through a clear,
user-friendly mobile interface.

> **Project status:** This repository contains design documentation and
> visual UI concepts only. It is not a developed or deployable mobile
> application. The screens illustrate proposed user flows and
> functionality.

## Project Overview

The design aims to make common healthcare tasks easier to navigate,
including discovering medical services, browsing doctors, scheduling
appointments, and accessing patient-related information.

The design approach is user-centered and informed by the project's
documented process: empathy, defining user needs, ideation, design, and
testing. The interface work focuses on usability, visual consistency,
accessibility, and streamlined workflows.

## Design Deliverables

The project is organized into the following design stages:

-   **Style Guide** -- visual direction and standards for colors,
    typography, iconography, and layout.
-   **Low-Fidelity Wireframes** -- early layouts showing screen
    structure and content hierarchy.
-   **Final UI Designs** -- high-fidelity mobile screen concepts.
-   **Prototype / Preview** -- visual previews of selected screens and
    proposed user journeys, where included.

## Selected Screens

The exported UI screens currently included in this repository cover:

-   Landing Screen
-   MEDTECH Home Page
-   Services List
-   Doctors by Category
-   Appointment Page
-   Profile Page

The wider design documentation also explores proposed areas such as
doctor profiles, payment flows, telehealth (voice, video, and
messaging), health articles, nearby medical facilities, favorites,
notifications, call history, reviews, medication, and medical records.
These are design concepts, not implemented or connected services.
